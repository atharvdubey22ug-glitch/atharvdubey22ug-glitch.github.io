# Atharv Dubey · portfolio

An interactive 3D optical bench: one beam runs past eight stations, one per project, each with a working model and a details panel.

- **S1 XY-01** — F²R compliant-flexure nanopositioning stage, meshed from `XY STAGE 1.step` ([design files](https://github.com/atharvdubey22ug-glitch/XY-Stage-files))
- **S2 ThreadScope** — the screwless multi-imaging microscope from the honours thesis
- **S3** IISc Quantum Materials Lab · **S4** Optical computing · **S5** Rocketry · **S6** RFID navigation · **S7** Distributed training · **S8** About & contact

Single self-contained `index.html` (three.js r128 from CDN). Live at https://atharvdubey22ug-glitch.github.io/
